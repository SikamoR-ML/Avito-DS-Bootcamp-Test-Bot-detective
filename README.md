# Детекция автоматизированного трафика Авито

Решение оценивает вероятность положительного класса для каждой `cookie_id` по событиям внутри указанного суточного окна. Готовый файл для сдачи: `submission.csv`.

## Состав

- `solution.py`: 134 базовых признака, обучение и сохранение моделей, создание ответа.
- `extra_features.py`: 12 дополнительных признаков User-Agent и поисковых запросов.
- `predict.py`: создание ответа из сохранённых моделей без повторного обучения.
- `validate.py`: воспроизведение четырёх временных сравнений.
- `metric.py`: официальная метрика с корректной обработкой одинаковых score.
- `artifacts/`: шесть обученных моделей и схема признаков.
- `BASELINE.md`: отдельно воспроизведённый исходный результат.
- `RESEARCH.md`: проверенные улучшения, метрики, ограничения и источники.
- `requirements.txt`: фиксированные версии локальных библиотек.

Исходные файлы `train.csv`, `test.csv`, `events.csv.gz` не публикуются. Их нужно разместить в `data/`.

## Запуск

Python 3.12.10. Случайность зафиксирована: `random_state=2026`.

```bash
python -m pip install -r requirements.txt
python solution.py
```

Для повторного предсказания без обучения:

```bash
python predict.py
```

Для проверки качества на последовательных периодах:

```bash
python validate.py
```

## Подход и результат

Используются события с `window_start_ts <= event_ts < window_end_ts`. Базовые признаки описывают объём активности, уникальные объявления и запросы, категории, поисковые страницы, интервалы, переходы между событиями, координаты курсора, платформу и возраст cookie. Дополнительные признаки описывают характер User-Agent и форму поисковых запросов. Отсутствующие числовые значения обрабатываются моделями; уровни категорий и порядок колонок фиксируются в `artifacts/feature_schema.json`. Идентификатор cookie и абсолютная дата не служат признаками.

Финальная оценка: 40% исходного ансамбля из двух LightGBM и CatBoost плюс 60% аналогичного ансамбля с 12 дополнительными признаками. На четырёх последовательных временных проверках средний Precision при Recall не ниже 70% вырос с 0.75322 до 0.76355; худший результат с 0.72959 до 0.73522. Детали, TP/FP и отклонённые эксперименты приведены в `RESEARCH.md`. Скрытая метрика для нового ответа пока неизвестна.

`submission.csv` содержит ровно 4909 строк и две колонки `cookie_id,score`, без пропусков и повторов. Повторное предсказание из сохранённых моделей даёт тот же файл. Использованы только локальные open-source библиотеки из `requirements.txt`; внешние API и предобученные большие модели не применялись.
